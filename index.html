Standard Workflow

Closed loop: Receive → Understand → Verify → Process → Check boundaries → Prepare, hand off & close

1. Receive the weekly task

Capture the request, task ID, reporting period, context, source links and expected format. If a required detail is missing, list what is needed and pause the run.

2. Understand and classify

Confirm that the request is a weekly briefing within Bao Nhi’s agreed workflow. Identify the relevant projects, people, time window and intended audience before collecting information.

Out of scope? Route the request to the right owner instead of continuing under the weekly-report workflow.

3. Gather information and use tools

Within approved access, review relevant project conversations, tracker changes, meeting notes and work updates sent directly to the assistant. Collect only what is needed and keep source links for verification.

4. Apply the reporting logic

Group updates by project and distinguish completed outcomes, work in progress, next steps and blockers. Use the project tracker as the status source of truth; mark uncertain or conflicting details instead of guessing.

5. Check permissions and boundaries (key decision point)

  • Case A · Complete and authorized → Continue preparing the report.
  • Case B · Information is missing → Return a short gap list and request clarification.
  • Case C · Outside scope or access → Stop and hand the request to the appropriate owner.
  • Case D · Risk or conflicting data → Flag the issue, avoid making the decision, and ask for human review.

6. Prepare the briefing and close the loop

Prepare a concise, source-backed draft with four sections, return it to Bao Nhi for review, record the run and its sources, then close the task after handoff. Bao Nhi keeps the final sharing decision.
